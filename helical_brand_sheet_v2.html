04 design principles
p.01
function over ornament
every element must earn its place. decoration is a failure of confidence. if it doesn't carry meaning, remove it.
p.02
lowercase as posture
we don't shout. all-caps is for people who don't trust their ideas. lowercase says: we already know what we're doing.
p.03
the grid is law
alignment is respect for the reader. consistent spacing signals that someone was paying attention when this was made.
p.04
monospace for the machine
courier for anything technical. it signals honesty — that the interface and the system beneath it are the same thing.
p.05
signal orange, used sparingly
one accent, used once per view. like a warning light on a control panel — it works because it's rare.
p.06
built to last
no trend-chasing. this system should read exactly the same in 2035. teenage engineering looked the same in 2012.
